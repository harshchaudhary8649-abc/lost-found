# Lost & Found

A simple web platform for reporting lost and found items and helping people connect with the right person.

## About

Lost & Found is a community-based platform where users can post details about items they have lost or found. Users can search through available posts, check item details, and connect with the person who posted the item.

The main goal of this project is to make the process of finding lost belongings easier and more organized.

## Features

* Post a lost item
* Post a found item
* Search for items
* Filter items by category and location
* View item details
* Upload item images
* User profiles
* Messaging between users
* Responsive design for mobile and desktop

## How It Works

### If you lost something

Create a lost item post with the item's name, category, location, date and other details. Other users can view the post and contact you if they have information about the item.

### If you found something

Create a found item post with the available details and images. The owner can search for the item and contact you.
