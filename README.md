## 💡 About

**Lost & Found** is a community-driven platform that bridges the gap between people who have lost valuable items and those who have found them. Our mission is to reunite people with their belongings while fostering a sense of community responsibility and care.

Whether you've lost your keys, wallet, phone, or any precious item, or you've found something that doesn't belong to you - this platform makes it easy to connect and find solutions!

---

## ✨ Features

### 🔍 Core Features
- **Post Lost Items** - Create detailed listings for items you've lost with images and descriptions
- **Post Found Items** - Help others by reporting items you've found
- **Smart Search** - Advanced filtering by category, location, date, and keywords
- **User Profiles** - Build trust with verified community members
- **Direct Messaging** - Secure in-app communication between users
- **Item Categories** - Organized browsing by type (Electronics, Documents, Accessories, etc.)

### 🛡️ Safety & Trust
- **Verified Users** - Community verification system
- **Ratings & Reviews** - Build credibility through feedback
- **Secure Messaging** - Encrypted communications
- **Report Inappropriate Content** - Keep the community safe

### 📱 User Experience
- **Responsive Design** - Works seamlessly on desktop, tablet, and mobile
- **Real-time Notifications** - Get alerts when matches are found
- **Map Integration** - Visualize lost/found locations
- **Image Gallery** - Upload multiple photos of your items
- **Wishlist** - Save items you're interested in

## 🚀 Getting Started

### Prerequisites

Before you begin, ensure you have the following installed:
- A modern web browser (Chrome, Firefox, Safari, Edge)
- A code editor (VS Code, Sublime, etc.)
- Git for version control

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/harshchaudhary8649-abc/lost-found.git
   cd lost-found
   ```

2. **Open in your browser**
   ```bash
   # Navigate to the project directory and open index.html
   # Or use a live server extension in VS Code
   ```

3. **Live Server Setup (Recommended)**
   - Install VS Code Live Server extension
   - Right-click on `index.html`
   - Select "Open with Live Server"

## 💻 Usage

### For Users Who Lost Items
1. Click on **"Post Lost Item"**
2. Fill in item details (name, description, category, location, date lost)
3. Upload high-quality photos of your item
4. Submit and monitor responses
5. Connect with finders through the messaging system

### For Users Who Found Items
1. Click on **"Post Found Item"**
2. Provide detailed description of what you found
3. Upload photos for identification
4. Wait for potential owners to contact you
5. Help reunite items with their rightful owners!

### Browsing & Searching
1. Use the search bar to find specific items
2. Filter by category, location, or date range
3. View item details and contact information
4. Send messages to users directly
